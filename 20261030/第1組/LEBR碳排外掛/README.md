# 第1組｜LEBR 低碳建築碳排外掛

在 Revit 建好模型後按一個按鈕，依《2025 低碳（低蘊含碳）建築評估手冊》（LEBR）算出建築的蘊含碳排、減碳率與 1+～7 級，並可匯出結果 JSON 給網頁做視覺化。

![結果視窗](截圖/2_result_tab1.png)
