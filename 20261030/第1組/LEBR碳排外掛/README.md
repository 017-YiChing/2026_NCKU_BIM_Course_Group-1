# 第1組｜LEBR 低碳建築碳排外掛

在 Revit 畫好模型後按一個按鈕，依《2025 低碳（低蘊含碳）建築評估手冊》（LEBR）算出建築的碳排放量和低碳等級（1+ 級最好，7 級最差），並可匯出結果給網頁做視覺化。

![計算結果](截圖/04_計算結果.png)

## 我要用外掛 → 看 [先看這個_快速開始.md](先看這個_快速開始.md)

五個步驟、每步都有截圖，不用會寫程式：

1. 雙擊 **安裝外掛.bat**（會自動找出你的 Revit 2024～2027）
2. 按「建立參數」
3. 在牆、窗、樓板的類型上填代號
4. 按「開始計算」
5. 匯出結果

> **注意**：GitHub 上的版本**沒有編譯好的外掛**（依本 repo 規則不放 DLL），雙擊 `安裝外掛.bat` 會提示找不到檔案。請向組員索取「外掛交接包」或「完整交接包」壓縮檔，裡面已附 Revit 2024～2027 四個版本。
