## 四、建置與測試

```
# 1. 純 C# 測試（不需 Revit）
cd "20261030\第1組\LEBR碳排外掛\lebr-db"
dotnet run --project csharp/LebrDatabase.Tests -f net8.0

# 2. 編譯並安裝（Revit 開著時使用新資料夾名稱）
powershell -ExecutionPolicy Bypass -File revit-addin/install.ps1 -RevitVersion 2027 -Folder LebrCarbon_<編號>
```

驗證基準：
- 附錄三：CFR 20.51%、1+ 級。
- 估算（不勾選估算時）：與附錄三一致。
